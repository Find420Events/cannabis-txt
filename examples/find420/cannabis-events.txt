1. PURPOSE
======================================================================

This file describes Find420.Events' role and public resources for
discovering cannabis-related events. It is a Find420.Events publisher
profile, not the generic cannabis-events.txt specification.

The specification is published at:
  https://find420.events/specs/cannabis-events.txt

======================================================================
2. PLATFORM ROLE
======================================================================

Find420.Events provides public event discovery pages and related
resources. It may list events submitted by organizers or other
publishers. Find420.Events is not necessarily the organizer or venue
operator for events shown on the platform.

A listing is not, by itself, a guarantee that an event is verified,
available, licensed, or accepting registration. Refer to the event
organizer's official information for current details.
Event information and applicable requirements may vary by jurisdiction.
Consult relevant official sources for jurisdiction-specific requirements.

6. DATA QUALITY AND PRIVACY
======================================================================

Event details can change. Users should confirm dates, locations,
registration, admission, and event status with the organizer or another
authoritative source.

This file does not publish private attendee identities, personal contact
information, invitation codes, or non-public venue access details.
Publication does not guarantee event verification, admission, search
ranking, or AI retrieval.
