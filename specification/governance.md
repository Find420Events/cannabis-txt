# Governance

The cannabis.txt specification family is a set of proposed community
specifications initially published by [Find420.Events](https://find420.events/).
Publication does not make them industry-approved or regulator-approved
standards.

## Stewardship

Find420.Events acts as founding steward: it hosts this repository, reviews
proposals, and publishes versions. Stewardship is administrative, not
proprietary — no publisher owns the industry taxonomy, and no publisher may
imply that compatibility requires using its services.

## Versioning

Each specification file uses [semantic versioning](https://semver.org):

- **MAJOR** — incompatible changes to definitions or required fields
- **MINOR** — backward-compatible additions
- **PATCH** — clarifications and corrections

Each file carries its own version number, status, published date, and
last-updated date where applicable. The current versions live at the repository
root; family-level changes are recorded in [CHANGELOG.md](../CHANGELOG.md) and
git tags.

## How to propose changes

- **Issues** — taxonomy proposals, definition discussions, corrections,
  implementation questions
- **Pull requests** — concrete text changes; describe the motivation and note
  whether the change is MAJOR, MINOR, or PATCH
- **Implementation reports** — tell us you published a compatible file; real
  adoption shapes the specification more than any single publisher's opinion

## Review principles

Changes should be documented, reviewed, and publicly versioned. Proposals are
weighed against the design principles in cannabis.txt §2: open,
human-readable, consistent, extensible, jurisdiction-aware, verifiable,
privacy-conscious, and non-exclusive.

Community participation may include public issue reporting, proposed taxonomy
changes, discussion of definitions, implementation examples, compatibility
testing, and version review.

No single publisher — including the steward — speaks for the entire industry.
The more independent adoption the specifications receive, the more meaningful
they become.
